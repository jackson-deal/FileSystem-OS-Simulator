README: File System Simulator (CS3502 Project 3)

This application is a functional File System Simulator built using C# and Windows Forms. It demonstrates core Operating System concepts including file handles, directory navigation, and POSIX-style error handling.
## Build & Run Instructions

To build and run this project locally, follow these steps:

    Environment Setup: Ensure you have Visual Studio (2019 or later) installed with the .NET desktop development workload.

    Create a New Project:

        Open Visual Studio and create a new Windows Forms App (.NET Framework) or Windows Forms App project.

        Name the project CS3502_P3_FileSystem_JacksonDeal to match the namespace.

    Import Source Files:

        Delete the default Form1.cs and Program.cs created by the template.

        Copy and add the provided Form1.cs, Form1.Designer.cs, and Program.cs files into your project folder.

    Add Reference: This project uses Microsoft.VisualBasic for input prompts.

        Right-click References in the Solution Explorer.

        Select Add Reference, find Microsoft.VisualBasic, and check the box to include it.

    Build and Run:

        Press F5 or click Start.

        The application will initialize in your system's Documents folder.
